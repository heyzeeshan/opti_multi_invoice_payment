# Portal Multi Invoice Payment with Card Surcharge

Portal customers select open invoices and pay them together.
The payment method surcharge percent is added as a line on every invoice in that payment.

## Install

Copy `opti_multi_invoice_payment` into your Odoo 17 addons path, update the app list, and install it.

## Configure

1. Open the payment method.
2. Set **Surcharge (%)**. Leave it at 0 when that method should not add a fee.
3. If the payment method already has a surcharge percent, that percent is used and a second line is not added.
